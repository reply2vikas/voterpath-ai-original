# VoterPath AI - Election Education Platform

An intelligent platform for learning about Indian elections using a Knowledge Graph architecture.

## Features

✅ **Knowledge Graph Based System** - Structured, organized learning
✅ **5 Learning Categories** - Organized by topic
✅ **10+ Knowledge Entries** - Comprehensive coverage
✅ **Confidence-Scored Responses** - Quality metrics
✅ **Educational Difficulty Levels** - Beginner to Advanced
✅ **Interactive Follow-up Suggestions** - Guided learning paths

## Tech Stack

- **Backend:** Node.js + Express.js

- **Architecture:** Knowledge Graph Database
- **Deployment:** Google Cloud Run

## Getting Started

```bash
npm install
npm start
```
